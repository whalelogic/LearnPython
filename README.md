## How the Repository Is Organized

Each top-level folder represents one learning topic and keeps its own README plus related guides nearby. That makes it easier to browse one subject at a time without having to jump through a central `/docs` index.

## Suggested Learning Path

1. Start in [fundamentals](fundamentals/README.md) for core syntax, values, and functions.
2. Move to [data_structures](data_structures/README.md) to learn how Python stores and organizes data.
3. Continue with [oop](oop/README.md) and [standard_library](standard_library/README.md) to write larger, more maintainable programs.
4. Use [regex](regex/README.md), [system](system/README.md), and [web](web/README.md) when you begin working with files, text, and APIs.
5. Explore [data](data/README.md) and [machine_learning](machine_learning/README.md) when you are ready for scientific Python workflows.
