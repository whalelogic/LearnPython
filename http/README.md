# HTTP Reference Library

This directory contains resources for understanding and working with HTTP in Python.

## Contents

- [HTTP_GUIDE.md](HTTP_GUIDE.md): Core concepts, status codes, methods, and `requests` library guide.
- [http_playground.py](http_playground.py): Runnable script demonstrating GET, POST, custom headers, and sessions.

## Quick Start

1. Install the `requests` library:
   ```bash
   pip install requests
   ```
2. Run the playground:
   ```bash
   python http_playground.py
   ```
