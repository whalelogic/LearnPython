# Dictionaries

Dictionaries map keys to values and are one of the most common ways to model structured data in Python.

## In This Folder

- [DICTIONARY.md](DICTIONARY.md) — a deeper dictionary reference with syntax, methods, and examples

## Quick Example

```python
profile = {"name": "Mina", "skills": ["python", "sql"]}
profile["active"] = True
for key, value in profile.items():
    print(key, value)
```
